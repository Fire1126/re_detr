## 新建 deploy/ —— 尾矿库检测演示

- `deploy/infer.py`：`TailingDetector` 封装「读配置 → 建模型 → 载权重 → 推理 → 画框」；
  CLI 支持单图/文件夹、`--score-thr`、`--save-txt`(DOTA格式)、`--json`、`--no-save`。
- `deploy/app.py`：标准库 `ThreadingHTTPServer` 做的 Web UI（无 gradio/flask，环境里都没装）。
  接口 `/api/info` `/api/samples` `/api/detect`；前端支持拖拽上传、粘贴本地路径、http(s) 地址。
- `deploy/README.md`：用法 + 参数 + 阈值/权重实测数据。

### 关键结论（实测，raw 权重）
- 推理 pipeline = `val_pipeline` 去标注：LoadImageFromFile → Resize(1024, keep_ratio) →
  Pad(1024, 114) → PackDetInputs。输出框已按 scale_factor 还原到原图坐标。
- **raw state_dict mAP 0.8337，ema_state_dict 只 0.7715**（EMAHook momentum=1e-4 窗口太长），
  所以默认必须用 raw。
- 阈值扫描（test 237 张，IoU 0.5 贪心匹配）：thr=0.5 时 P 0.911 / R 0.894 / F1 0.903 最优；
  thr=0.3 时 P 0.84 / R 0.92。演示默认 0.5。
- 单图推理 4090 上 ~20-60ms（首帧 240ms 是 cuDNN 选核，已加预热）。

### 环境坑（重要）
bash 工具起的 shell 有 `ulimit -v 4GB`、`nproc 4096` 硬限制，直接跑 python 会报
`libnvJitLink.so.12: failed to map segment` 或 numpy `CPU dispatcher tracer already initlized`。
解决办法：用 `systemd-run --user --collect --wait --pipe bash -c '...'` 启动（拿到干净限制），
同时设 `OPENBLAS_NUM_THREADS=4`。演示服务用 `systemd-run --user --unit=tailing-demo` 常驻。

### 后续修正（用户反馈后）
- **不要把演示服务常驻在 7860**：用户自己 `python deploy/app.py` 会撞
  `Errno 98 Address already in use`。改完就 stop，或让程序自动顺延端口。
- `app.py` 增加 `_bind()`：端口占用自动 +1 试 20 次，失败才报错退出。
- 警告噪音来源：**import torch 会重置/插入 warnings 过滤器**（`torch.distributed.optim`
  自己插了个 `once` 再打印 TorchScript DeprecationWarning）。做法：`catch_warnings` +
  `contextlib.redirect_stderr` 静音那一次导入，导入后再 `_quiet_warnings()` 重装过滤器。
- 入口处 `sys.stdout.reconfigure(line_buffering=True)`，否则输出重定向到文件时日志全丢。
