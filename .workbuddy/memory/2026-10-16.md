# 2026-10-16

## 为 tailing 数据集训练配置新增两种数据增强

需求：在 `projects/rotated_rtdetr/configs/o2_rtdetr_r50vd_2xb4_72e_tailing.py`
（继承 `tailing.py`）的训练集上加入「平移变换」和「高斯噪声」。

改动：
- `mmrotate/datasets/transforms/transforms.py`：新增并注册两个变换
  - `RandomTranslate`：旋转框友好的平移（mmdet.RandomShift 对 RotatedBoxes
    会告警且不移除移出画面的框；本实现用 pad_val 填充边界，并剔除中心移出
    图像的框）。
  - `RandomGaussianNoise`：高斯噪声，支持 prob / mean / sigma(标量或区间) /
    per_channel / clip / clip_range，int 图按 dtype 范围裁剪。
- `mmrotate/datasets/transforms/__init__.py`：导出上述两个类。
- `projects/rotated_rtdetr/configs/tailing.py`：train_pipeline 在 `RandomRotate`
  之后插入 `RandomTranslate(prob=0.5, max_shift_px=100, pad_val=114)` 与
  `RandomGaussianNoise(prob=0.5, mean=0.0, sigma=(5.0,15.0))`。
  高斯噪声必须放在 `PhotoMetricDistortion` **之前**（此前图像是 uint8/0-255，
  sigma 尺度直观；之后会变成 float32）。

验证：RandomTranslate 200 次试验（保留框中心全在图内）；RandomGaussianNoise
100 次试验 + prob=0 无操作 / per_channel / sigma=0 边界；真实数据集完整
train_pipeline（11 步，含 Pad/PackDetInputs）跑通 3 个样本。

环境注意：本沙箱有 4GB 虚拟地址空间上限（`ulimit -v`，硬限制不可改），
导入 torch 后几乎占满，大图分配易 OOM。跑验证脚本需加
`CUDA_VISIBLE_DEVICES="" MALLOC_ARENA_MAX=1 OMP_NUM_THREADS=1` 并
`cv2.setNumThreads(1)`。真实训练不受此限。
